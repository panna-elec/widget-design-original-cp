# アップロード前の情報確認

2026-11-26、panna-elecのPrivateリポジトリへの初回保存前に実施。

## 対象

準備済み74ファイルについてGitのindexから実際の送信内容を読み、作業フォルダとの一致を確認。この確認記録を追加した初回コミットは75ファイル。旧プロジェクトのGit履歴は引き継がない。

## 確認結果

- ファイル名・フォルダ名とUTF-8本文を確認。利用者の氏名、端末ユーザー名、個人メール、ユーザーフォルダの絶対パス、研究・別アプリの名称は検出なし。
- トークン、秘密鍵、代表的なAPI資格情報形式を走査し、検出なし。URL一覧に資格情報付きURLや個人用サービスへのリンクなし。
- 3枚のPNG壁紙を目視確認。幾何学的な背景で、氏名・ファイル名・デスクトップ画面の写り込みなし。PNGチャンクはIHDR/IDAT/IENDのみで、テキスト・EXIFなし。
- 3枚のSVG壁紙に文字要素由来の本文や外部画像参照なし。
- 3書体ファイルのnameテーブルを読み、制作端末の個人情報を含まないことを確認。公表されているフォント作者・著作権者の名前と連絡先はライセンス遵守のため保持。
- 個人のタスク・リンク・配置状態、ログ、スクリーンショット、バックアップ、ビルド済み実行ファイル、認証ファイルは対象外。
- コミットのauthor/committerには公開用ハンドルpanna-elecとGitHubのnoreplyメールを指定し、送信前に確認する。

この確認はファイル名・内容・メタデータと初回Git履歴を対象とする。ライセンスや一般公開可否の確認とは別であり、権利の扱いは[RIGHTS_AND_LICENSES.md](../RIGHTS_AND_LICENSES.md)を参照。
