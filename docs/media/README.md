# README用スクリーンショット・アニメーション

撮影日: 2026-11-27。最新のHTML/CSS/JavaScriptをローカルブラウザーで動かし、**英語表示**で撮り直したもの。画像生成による想像図ではない。

- 使用画面: 実装のsurface.htmlを隔離したプレビュー用iframeで起動。REFERENCE・左配置・通常演出。
- メイン画面: 1440×1080。クリムゾン、大きさ115%、線幅130%。
- 設定画面: 大きさ130%、線幅160%。保存後、選択欄へスクロールした実画面。
- 英語選択時も、言語セレクターの共通ラベル「表示言語 / Language」と選択肢「日本語」は残る。元から英語の見出しは変更しない。
- 数値・Wi-Fi接続表示: プレビューの仮データ。時計は撮影時刻。実機ファイル・タスク・リンク・個人設定を読まず、専用のローカルプレビュー保存領域を使用。
- JPEG: ブラウザーから直接保存。画面の合成・描き足しなし。
- GIF: 連続スクリーンショットから約0.2秒間隔のフレームを選び、一時作業用Pillow 13.0.0で1080×810・256色のループGIFへ変換。操作間の長い待ちだけ短縮。色や光の強度の強調は行わず、縮小と減色のみ。
